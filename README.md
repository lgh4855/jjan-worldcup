# 🍻 짠! 월드컵

술자리에서 친구들이랑 같이 하는 이상형 월드컵 게임. 둘 중 하나를 고르는 방식으로 16강·32강 토너먼트를 진행해요.
빌드 과정 없이 `index.html` 파일 하나로 돌아가요.

## 월드컵 목록 (12종)
술안주(32) · 술(16) · 야식(32) · 여행지(32) · 최악의 상황(16) · 이상형 조건(32) · 초능력(16) · 다시 태어난다면(16) · 데이트 코스(16) · 편의점 간식(16) · 추억 소환(16) · 술게임(16)
+ **나만의 월드컵**: 후보를 직접 적거나 친구들 사진을 넣어서 만들기

## 술자리 모드 🍶
- **하나, 둘, 셋!** 버튼을 누르면 카운트다운이 나와요. 다 같이 동시에 한쪽을 가리켜요.
- 다수가 고른 쪽을 누르면 → 진 쪽을 가리킨 사람(소수파)이 한 잔
- 5경기마다 **랜덤 미션 카드**가 나와요 (러브샷, 건배사 등)
- 우승을 미리 맞춘 사람은 벌주 면제

## 폰 여러 대로 같이 하기 (실시간)
방장이 방을 만들면 4자리 방 코드와 QR이 나와요. 친구들은 QR을 찍거나 코드를 입력해서 들어와요.
- **📺 방장 화면 공유** (`sync.html`): 방장이 카드를 고르면 모든 참가자 폰이 같은 화면으로 넘어가요. "하나, 둘, 셋!" 카운트다운도 모두의 폰에 같이 떠요.
- **🗳️ 다 같이 투표** (`vote.html`): 각자 폰으로 몰래 투표 → 다 투표하면 자동 공개. 소수파 이름이 "한 잔: ○○"으로 불리고, 동점이면 방장이 결정해요. 오늘의 술고래(벌주 누적)도 집계돼요.

실시간 연결은 공개 MQTT 브로커(`broker.emqx.io`)를 써요. 가입이나 서버가 필요 없지만, 방 코드를 아는 사람은 누구나 들어올 수 있어요. 방 상태는 방장 폰이 관리해서, 방장이 앱을 끄면 진행이 멈춰요 (다시 열면 같은 방으로 자동 복귀).

## 그 밖의 기능
- 되돌리기(↶), 키보드 ←/→ 로 선택
- 우승까지의 길, 이 기기에 쌓이는 누적 우승 랭킹
- 결과 복사 (단톡방에 붙여넣기)

## GitHub Pages로 배포하기
1. GitHub에서 새 저장소를 만들어요 (예: `jjan-worldcup`, Public).
2. 이 폴더에서:
   ```bash
   git remote add origin https://github.com/<내아이디>/jjan-worldcup.git
   git push -u origin main
   ```
3. 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`로, Branch를 `main` / `/ (root)`로 설정하고 Save를 눌러요.
4. 1~2분 뒤 `https://<내아이디>.github.io/jjan-worldcup/`에 접속하면 돼요.

## 후보 추가 / 수정하기
`data.js`에 있는 `RAW` 배열을 고치면 돼요. 후보는 `"이모지 이름"` 형식으로 쉼표로 구분해요.
```js
{id:'anju',t:'술안주 월드컵',d:'오늘 밤 최고의 안주는?',h:'#ff5a1f',e:'🍢',
 L:'🍗 후라이드 치킨,🌶️ 양념치킨,🥓 삼겹살,...'}
```
- 후보 수가 2의 거듭제곱(16, 32, 64)이면 모든 라운드가 꽉 차요. 다른 수여도 그 이하의 가장 큰 크기로 무작위로 뽑아요.
- 새 월드컵을 만들려면 블록 하나를 복사해서 `id`를 바꾸면 돼요.
